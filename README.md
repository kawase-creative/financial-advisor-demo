# 財務経理顧問事務所 デザイン提案用デモ

黒・チャコール、オフホワイト、シャンパンゴールドで構成した静的サイトです。元メガバンク支店長／現・非上場企業取締役という提供経歴以外の資格・実績・成果は掲載していません。

## ページ構成

- `index.html` トップ
- `services.html` サービス紹介
- `strengths.html` 当事務所の強み
- `profile.html` 代表者紹介
- `office.html` 事務所概要
- `contact.html` お問い合わせ
- `privacy.html` プライバシーポリシー仮案（補助ページ）

`assets/style.css`：共通レイアウトとレスポンシブ。`assets/config.js`：カテゴリ・送信先設定。`assets/app.js`：メニュー、dialog、フォーム、IntersectionObserver。

## 操作とローカル確認

展開したフォルダの `index.html` をブラウザで開いて確認できます。外部ライブラリ・フォント配信・バックエンドへの依存はありません。

お問い合わせCTAはJavaScript対応ブラウザでdialogを開きます。スマホ幅600px以下は全画面。非対応ブラウザ／JavaScript無効時はお問い合わせページに遷移します。モーダルはEsc・閉じるボタン・PCの背景クリックで閉じます。モバイルメニューはEscとTab循環に対応しています。

送信先は `contact@example.invalid` です。.invalidはダミー用のドメインです。必須入力チェック後、URLエンコードした氏名・電話・メール・カテゴリ・任意本文をmailtoリンクへセットします。メールアプリが起動するかは端末環境次第です。送信完了は表示せず、フォーム内容も削除しません。再起動用リンクを表示します。入力内容のサーバー送信やlocalStorageへの保存は実装していません。公開デモへ実際の個人情報・機密情報を入力しないでください。

## GitHub Pages

公開サイト：https://kawase-creative.github.io/financial-advisor-demo/

リポジトリ：https://github.com/kawase-creative/financial-advisor-demo

新規publicリポジトリのmainブランチ、ルートからPagesで配信しています。HTTPS有効。既存リポジトリは変更していません。`.nojekyll` により静的ファイルをそのまま配信します。

`review/viewport.html` は公開サイトの可変幅確認用補助画面です。サイトナビゲーションには含めず、noindexに設定しています。CSSには更新番号を付けてキャッシュを更新しています。

別のリポジトリ名を使う場合は全HTMLの `og:image` を実際のURLに変更してください。正式公開後はcanonicalとog:urlを実際のURLで各ページに追加してください。

## SEO・アクセシビリティ

ページ固有のtitle・description、OGP基本項目、lang、viewportを設定。セマンティック要素、h1、スキップリンク、aria-current、フォームラベル、aria-invalid、エラー文、role=status、フォーカス表示があります。

正式受注前の仮情報が検索結果へ露出しないよう、全ページに `noindex, nofollow` を設定しています。本番の正式原稿への置き換え後に削除し、サイトマップとcanonical等を追加してください。これは本番SEOを放棄する設定ではなく、デモ限定の扱いです。

## 画像と素材

`assets/consultation.webp` と `assets/ogp.jpg` は今回生成した相談室のイメージです。実在の事務所・人物を撮影した素材ではありません。第三者のストックフォトや参考画像の切り出しは使用していません。代表者エリアは正式写真掲載予定のプレースホルダーです。仮ロゴ・アイコンは独自SVG、フォントは各端末のシステムフォントです。写真は彩度・コントラストを控えめにし、画像altにもイメージ素材であることを記載しています。正式公開前に実写真への差替えを推奨します。

生成プロンプト概要：静かな日本の相談室、ウォールナットの机、ノートとペン、チャコールの椅子、曇りの日の自然光、窓の外に一般的な都市ビル。人物・文字・ロゴなし。低彩度、低コントラスト、HDRや発光演出なし。使用方式：imagegen組み込みツール。

## 原稿の差替え・WordPress移行

サービス仮分類は `services.html` と `index.html` にまとまっています。カテゴリは `config.js` に集約。JavaScript無効時も表示するカテゴリは各HTML内にも保持するので併せて編集してください。ダミー送信先の変更時は設定値と各HTML内の説明文の両方を更新してください。

HTML内のheader/footer/dialogをWordPress共通テンプレートに、ページ本文を固定ページに分離できます。写真・略歴・事務所概要・サービスをカスタムフィールド化する想定です。サーバー側送信サービスへの移行時は `app.js` のmailtoアダプタを置き換え、サーバー側の検証、エラー・成功表示、プライバシーポリシーを実際の運用に合わせて実装してください。GitHub PagesではPHP／WordPressは動きません。
